# 📄 Static Page (Página Estática)

> Um projeto fundamental focado nas estruturas base do desenvolvimento web, construído puramente com HTML5 e CSS3 sem o uso de frameworks.

👉 **[Acesse a página online aqui](https://static-page-taupe-one.vercel.app/)**

---

## 🚀 Sobre o Projeto

Este projeto representa os meus primeiros passos práticos no desenvolvimento frontend. Trata-se de uma landing page estática desenvolvida com o objetivo de consolidar os conceitos essenciais da web: estruturação semântica de elementos, estilização visual, tipografia, espaçamentos e os primeiros contatos com layouts responsivos organizados no CSS.

## 🎯 Conceitos Praticados

- 🏗️ **HTML5 Semântico:** Uso correto de tags como `<header>`, `<main>`, `<section>` e `<footer>` para melhor acessibilidade e SEO.
- 🎨 **Estilização CSS3:** Manipulação de cores, fontes, bordas e propriedades de caixa (`box model` - padding, margin e border).
- 📐 **Posicionamento:** Compreensão do fluxo de renderização de elementos em bloco (block) e em linha (inline).
- ⚡ **Hospedagem Moderna:** Configuração de deploy contínuo direto na nuvem através da Vercel.

## ⚙️ Como Executar o Projeto Localmente

Por se tratar de um site estático puro, a execução local é extremamente simples e não necessita de nenhuma instalação ou gerenciador de pacotes.

### 1. Clonar o Repositório

```bash
git clone [https://github.com/FelipeDelfinoDev/static-page.git](https://github.com/FelipeDelfinoDev/static-page.git)
cd static-page
```

### 2. Abrir no Navegador

Basta abrir a pasta do projeto no seu editor de código (como o VS Code) e utilizar a extensão Live Server clicando com o botão direito no arquivo index.html e selecionando "Open with Live Server".
